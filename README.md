# SkillForge AI

SkillForge AI is an AI-powered career assistant that helps students improve their software development skills through CV analysis, personalized learning paths, interview preparation, and Retrieval-Augmented Generation (RAG).

## Tech Stack

- Python
- Microsoft Foundry Local
- SQLite
- Streamlit
- RAG
- Git & GitHub
