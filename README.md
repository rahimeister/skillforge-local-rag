# SkillForge AI

SkillForge AI, öğrencilerin ve kariyerine yeni başlayan geliştiricilerin kariyer gelişimini desteklemek için geliştirilen yapay zekâ destekli bir kariyer asistanıdır.

Uygulama; CV analizi, kişiselleştirilmiş öğrenme planı, mülakat hazırlığı ve belge tabanlı soru-cevap özelliklerini bir araya getirir.

## Proje Amacı

SkillForge AI'ın amacı, kullanıcının mevcut becerilerini ve kariyer hedeflerini dikkate alarak kariyer gelişim sürecini daha düzenli ve kişiselleştirilmiş hale getirmektir.

## Özellikler

- CV yükleme ve metin çıkarma
- Yapay zekâ destekli CV analizi
- Kişiselleştirilmiş öğrenme planı arayüzü
- Teknik ve İK mülakat hazırlığı
- Belge tabanlı soru-cevap (RAG)
- Yerel yapay zekâ modeli kullanımı

## Kullanılan Teknolojiler

- Python
- Streamlit
- Microsoft Foundry Local
- OpenAI Python SDK
- pypdf
- SQLite
- RAG
- Git & GitHub
